DGM Muse proposal

A model proposal is bounded advisory text for the existing fixture evaluation. Nothing executes, promotes or reserves. Live mode stays off unless the server reports it configured; a fixture dry run performs no provider call. Submit synthetic qualification input only — never tenant, credential, personal or production data.
